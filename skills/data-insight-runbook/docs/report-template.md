# 报告模板与严谨性检查清单（report-template）

数据洞察报告的固定骨架。产出时严格按此结构，并在交付前过完下方的严谨性检查清单。

## 报告骨架

```markdown
# {主题}数据洞察报告

> 数据源：{文件路径 / 粘贴 / DuckDB 连接类型}
> 时间范围：{起止}　粒度：{日/周/月}
> 生成时间：{时间}　工具：dsh-data-insight v{版本}

## 一、核心结论
1. **{结论}**：{具体数字支撑}（见「三/四/五」节）
2. …
（3–5 条，每条带数字）

## 二、数据概况
- 行数 / 列数 / 编码 / 分隔符
- 缺失值概览（哪些列缺失、缺失率）
- 数据质量问题与处置（重复、单位、异常格式）

## 三、关键指标
| 指标 | 值 | 口径 |
|---|---|---|
| … | … | … |
（汇总统计：总数/均值/中位数/环比/同比…）

## 四、趋势与对比
- 趋势图（三通道，见 docs/chart-spec.md）
- 解读：涨跌与关键拐点，附数据表格

## 五、TopN 与异常
- TopN 表（N=5，并列标注）
- 异常值表（值 + 所属维度 + 判定依据）

## 六、风险与建议
- 【事实】…（纯数据陈述）
- 【推断】…（模型分析，标注依据与置信度）
- 建议（可执行、对应到具体数字）

## 附录 A：口径与可复现说明
- 数据源、过滤条件、缺失/重复处置
- 算法与参数（同环比基准期、TopN 取值、异常阈值 Z=3 / IQR）
- 核心指标计算公式
- 图表数据表（每个图的数据源）

## 附录 B：探查记录
- Schema（列名 + 推断类型）
- 值分布摘要
```

## 严谨性检查清单（交付前逐项过）

| # | 检查项 | 通过标准 |
|---|---|---|
| 1 | 结论有数字 | 每条核心结论引用至少一个具体数字，数字可在正文/附录查到 |
| 2 | 事实/推断分离 | 「风险与建议」用【事实】【推断】明确标注；推断给出依据 |
| 3 | 口径可复现 | 附录含过滤条件、聚合方式、计算公式、算法参数 |
| 4 | 图数一致 | 每个图表数据点都能在附录表格找到 |
| 5 | 不编造 | 无探查依据的数字不出现；缺失值处置如实记录 |
| 6 | 单位与小数位 | 全文单位统一（万元/元/人…），小数位一致 |
| 7 | 时间口径明确 | 起止日期、粒度、时区（如涉及时区）写明 |
| 8 | 脱敏 | 附录不含密码/密钥；连接串脱敏 |

任一条不过，回到对应阶段返工，禁止「应该没问题」式收尾。

## 精简版（用户要求「快速看一眼」时）

保留：核心结论 + 数据概况 + 关键指标表 + 一个图表（趋势或 TopN）。
豁免：完整趋势解读、附录 B。**不豁免**：检查项 1（结论有数字）、2（事实/推断分离）、8（脱敏）。
